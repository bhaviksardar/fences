Fence your agent

Wrap the agent with its limits and call checkpoint() after each model call.

import agentfences
from agentfences import governed, checkpoint, log_decision

agentfences.init(api_key="fc_...", endpoint="")

@governed(budget_usd=1.00, max_iterations=50)
async def my_agent(task):
    while True:
        log_decision(reasoning="deciding next step", action="llm_call")
        response = call_llm(task)
        result = await checkpoint(cost_delta_usd=0.01, tokens_used=500)
        if result.breached:
            return result.message

Limits

Rules each API key's agents can't change. Per-run limits cap every run, whatever the agent asks for. Daily and monthly caps cover all of a key's runs together. An agent name stops a key reporting as any other agent. Leave a field empty for no limit.
