How it works

Wrap the loop. Checkpoint each step.

01pip install agentfences and point it at your Fences key.
02Decorate the agent with its limits.
03Call checkpoint() after each model call. Breaches come back as a result, not an exception.
import agentfences
from agentfences import governed, checkpoint, log_decision

agentfences.init(api_key="fc_...", endpoint="https://your-fences-instance.com")

@governed(budget_usd=5.00, max_iterations=300, max_tokens=500_000)
async def research(messages):
    while True:
        log_decision(reasoning="searching sources", action="search")
        response = call_llm(messages)

        result = await checkpoint(
            cost_delta_usd=cost(response.usage),
            tokens_used=response.usage.total_tokens,
        )
        if result.breached:  # budget_exceeded, iteration_limit, ...
            messages.append({"role": "system", "content": result.system_prompt})
            return call_llm(messages)  # wrap up gracefully

FAQ

Questions.

Does Fences call my LLM or see my prompts?

No. Your agent reports cost, tokens and an optional short reasoning note at each checkpoint. Prompts and completions never leave your infrastructure.

What happens when a limit is crossed?

The checkpoint returns breached with the reason (budget_exceeded, iteration_limit, time_limit or token_limit), the run is marked breached, and further checkpoints are refused until you raise the limit.

Which frameworks does it work with?

Anything with a loop. Fences doesn't care whether you use raw API calls, LangChain or your own orchestrator. You call checkpoint() where a step ends.

Can I try it without an account?

Yes. agentfences.init(local_only=True) enforces limits in-process with no key. Add an API key when you want the dashboard and the stored audit trail.

How do I sign in?

Google, GitHub, Microsoft, Apple, email and password, or your company's SAML/OIDC SSO.
