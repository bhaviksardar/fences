The control plane for AI agents.

Fences gives organizations visibility and control over every AI agent interacting with their systems, regardless of where it runs or who built it.

Fences dashboard · Cloud preview

Observability tells you what happened. Fences stops it.

Tracing shows a runaway agent after the bill arrives. Fences sits inside the agent loop, so every step is checked against limits the agent can't raise, and you can stop any run while it's still running.

  • Breaches return, they don't crash. The agent gets a ready-made message to wrap up with.
  • Model calls are checked before they're sent, at their worst-case cost.
  • Prompts and outputs stay in your process by default.

What Fences enforces.

Every control is enforced in the SDK, and on the server when you connect to Fences Cloud.

Hard limits

Spend, steps, time and tokens per run, plus daily and monthly caps per agent. Set in code or from the dashboard; the agent can't raise them.

@governed

One-click stop

Stop any run from the dashboard. Its next step is refused with a clear reason, and a run stuck in a tool is cut off after a grace period.

stopped_by_user

Guarded tools and approvals

Refunds, payments and deploys ask Fences before they run, reserve what they cost, and can wait for a person to approve. Blocked means the code never ran.

guard=True

Checked before the call

Each OpenAI or Anthropic call is priced at its worst case before it's sent. Parallel calls hold their share, so they can't overspend together.

instrument=True

Decision trail

What the agent did and why, step by step, on a timeline where retry loops and slow steps stand out.

log_decision

Raise and resume

A run hit its limit but should finish? Raise the limit and it carries on at the next checkpoint, with no redeploy.

on_breach="hold"

One key per agent

Each agent gets its own key, so one runaway can't spend another's budget, read its runs or report as it.

Wrap the loop. Checkpoint each step.

  1. Install agentfences and call init(). Local mode needs no key.
  2. Govern the agent with its limits, and guard the tools that act on the world.
  3. Pass each model response to checkpoint(). Fences prices it, and a breach comes back as a result.
import agentfences
from agentfences import governed, checkpoint, log_decision

agentfences.init(local_only=True, instrument=True)

@agentfences.tool(
    cost_usd=lambda order, amount: amount, approve=True
)
def issue_refund(order, amount): ...  # runs if allowed

@governed(budget_usd=5.00, max_iterations=300)
async def support(messages):
    while True:
        log_decision(reasoning="checking the order",
                     action="lookup")
        response = client.chat.completions.create(
            model="gpt-4o", messages=messages
        )

        result = await checkpoint(response)  # priced from usage
        if result.breached:
            messages.append({"role": "system",
                             "content": result.system_prompt})
            return call_llm(messages)  # wrap up gracefully

Common questions.

Does Fences call my LLM or see my prompts?

No. Your agent reports cost, tokens, the model's name, an optional reasoning note, and which tools it called, with their argument names. Prompts, completions and argument values stay in your infrastructure by default. A guarded tool's check sends its arguments so rules can apply, and a redact hook sees everything before it's sent, so you can change or drop any of it.

What happens when a limit is crossed?

The checkpoint returns breached with the reason: a run limit (budget_exceeded, iteration_limit, time_limit, token_limit), the agent's daily or monthly cap, or stopped_by_user. The agent gets a ready-made message to wrap up with, and further checkpoints are refused until you raise the limit. With on_breach="hold" the run waits instead, and carries on once someone raises the limit.

Which frameworks does it work with?

Anything with a loop, in Python or TypeScript. Raw OpenAI and Anthropic calls are recorded and checked against the budget before they're sent. LangChain, LangGraph and the OpenAI Agents SDK need no decorators, and MCP tool calls are recorded and can be guarded. Otherwise you call checkpoint() where a step ends, and agents in any other language can use the REST API.

Can I try it without an account?

Yes. agentfences.init(local_only=True) enforces limits in-process with no key. Fences Cloud, with the dashboard and stored audit trail, is coming soon.

How do I sign in to Fences Cloud?

Google, GitHub, Microsoft, Apple, email and password, or your company's SAML or OIDC single sign-on.
