What it does

Three problems.
One decorator.

Agents fail in predictable ways. Fences catches all three before they become incidents.

💰

Budget enforcement

Set a spend limit per run. The moment cumulative cost crosses it, the agent stops with a clean exception — not after the fact.

BudgetExceeded
🔁

Loop protection

An agent can stay within budget and still loop forever on a cheap model. Iteration and time limits catch what spend control misses.

IterationLimitReached
📋

Decision audit trail

Agents record why they did something at each step. When a run breaches a limit, the full reasoning trail is preserved for debugging.

log_decision()

Quickstart

Works with any agent.

agent.py Python 
import fences
from fences import governed, checkpoint, log_decision
from fences import BudgetExceeded, IterationLimitReached

fences.init(local_only=True)

@governed(
    budget_usd=0.50,
    max_iterations=20,
    max_duration_ms=60_000
)
async def run_agent(query: str):
    for step in range(100):
        log_decision(
            reasoning=f"step {step}: searching",
            action="web_search"
        )
        await checkpoint(cost_delta_usd=0.02)

try:
    await run_agent("research this topic")
except BudgetExceeded as e:
    print(f"Stopped: ${'{'}e.spent_usd:.4f{'}'} spent")
except IterationLimitReached as e:
    print(f"Stopped: {'{'}e.iterations{'}'} iterations")

Reference

Limits and exceptions

Exception Parameter When it fires
BudgetExceeded budget_usd Cumulative spend across all checkpoint() calls exceeds the limit.
IterationLimitReached max_iterations checkpoint() has been called more times than the iteration limit allows.
TimeLimitReached max_duration_ms Wall-clock time since the run started exceeds the duration limit.
